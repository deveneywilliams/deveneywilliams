# Hi, I'm Deveney.

I run [Sunny Side Up](https://ssustudio.com), a Boston creative agency, and I'm a designer and marketer who builds the tools our agency needs with AI. This is where I build in public: small experiments, what worked, what broke.

## What I use AI for

The unglamorous work that keeps a small agency running. Claude double checks my data, syncs my contacts, does the research, and drafts the follow ups I edit before anything goes out. It also runs the audits and monthly cleanups nobody has time to do by hand.

## How we build websites

Every site we build now starts in Claude Code. The bigger change is that checks that used to be "we'll get to it" now run before launch: speed, accessibility, search, and how AI tools find and cite a site.

For example, scanning our own homepage turned up one real issue: a footer label that missed the contrast bar by half a point. Small, fixable, and exactly what a human eye skips.

## Why I build in public

It's fun, and AI is new enough that nobody has the full playbook. You never know whose problem your weird little tool solves.

## What's here for you

If you run a small team, or you are the team: audits, cleanups, checklists, and tools you can copy.
